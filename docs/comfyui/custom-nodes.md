# Custom nodes

Install via ComfyUI Manager, or git clone into `ComfyUI/custom_nodes/`.

| Pack | Repo | Required on |
| --- | --- | --- |
| ComfyUI-GGUF | https://github.com/city96/ComfyUI-GGUF | 2070 |
| comfyui_controlnet_aux | https://github.com/Fannovel16/comfyui_controlnet_aux | both (preprocess); vast (full CN) |
| ComfyUI-FluxTrainer | https://github.com/kijai/ComfyUI-FluxTrainer | vast (or 2070 experiments) |

FluxGym (vast template) does **not** need FluxTrainer if you train in the Gradio UI.
